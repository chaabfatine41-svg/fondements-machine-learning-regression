# fondements-machine-learning-regression

# Fondements du Machine Learning et analyse comparative des méthodes de régression
## 1. Présentation du projet

Ce projet consiste à étudier les fondements du Machine Learning et à comparer plusieurs méthodes de régression en utilisant Python et la bibliothèque Scikit-learn.

## 2. Objectifs

- Comprendre les bases du Machine Learning.
- Préparer et diviser un jeu de données.
- Entraîner plusieurs modèles de régression.
- Évaluer les performances des modèles.
- Comparer les résultats afin d'identifier le modèle le plus performant.

## 3. Jeu de données

Le projet utilise le jeu de données Diabetes intégré à Scikit-learn. Il contient des caractéristiques médicales et une variable cible représentant la progression de la maladie.

## 4. Méthodes étudiées

- Régression linéaire (Linear Regression)
- Régression Ridge
- Régression Lasso
- Arbre de décision (Decision Tree)
- Forêt aléatoire (Random Forest)
- Support Vector Regression (SVR)

## 5. Méthodologie

1. Chargement du jeu de données.
2. Exploration et préparation des données.
3. Division des données en ensembles d'entraînement et de test.
4. Entraînement des modèles.
5. Évaluation des performances.
6. Comparaison des résultats et visualisation.

## 6. Métriques d'évaluation

- MAE : Mean Absolute Error
- MSE : Mean Squared Error
- RMSE : Root Mean Squared Error
- R² : coefficient de détermination

## 7. Technologies utilisées

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## 8. Résultats

Les performances des modèles seront comparées à l'aide des métriques d'évaluation et d'un graphique. Le meilleur modèle sera identifié selon les résultats obtenus sur les données de test.

## 9. Conclusion

Ce projet permet de comprendre les principales méthodes de régression et d'analyser leurs performances sur un même jeu de données.
